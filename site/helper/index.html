Questions, answered

Is Vozen Helper available now?

Yes. Helper is publicly available. Install it from this page, choose a server, and configure your first module through the guided setup.

Does Helper request Administrator?

No. The base invite uses limited permissions and never requests Administrator. If a module needs an additional sensitive permission, Helper explains why before you enable it.

How do I get started?

Install Helper, choose your server, complete the guided setup, enable one module, and run its first useful action.

Which modules does Helper include?

Helper brings together protection and moderation, tickets, roles and community tools, events, automation, and operational insights. The panel shows the exact options available to your server.
